Hi, I'm Anand. I'm a software engineer at Microsoft in the Office of the CTO, working on the services behind agentic AI features in Microsoft 365. Most of what I do sits under the product: latency budgets, failure handling, identity, and the platform that ships it.

Before Microsoft I was a co-op at Kyndryl, working on an API gateway, single sign-on across a set of Java services, and a recommendation service built on retrieval. I spent three years before that at Oracle on enterprise integrations, identity and support tooling. MS in Computer Science, Northeastern.

There's a longer version, with case studies, at **[anandms.com](https://www.anandms.com)**.

### Selected work

- **[Campus Cloud Print Queue](https://github.com/anandms101/Campus-Cloud-Print-Queue).** Cloud printing on AWS where a job prints exactly once, even when it's released twice. It's a Go API, Python workers, a queue per printer, and DynamoDB conditional writes instead of locks. We were a team of three, and I did the Terraform, CI/CD and resilience layer. [Case study](https://www.anandms.com/work/campus-print-queue)
- **[Stock sentiment analysis](https://github.com/IBMStockTrader/stock-sentiment-analysis).** A RAG service I built at Kyndryl for the Stock Trader demo. It's hybrid search with reciprocal rank fusion, Azure OpenAI, and Redis caching with a lifetime per kind of data, and it's open source under Apache 2.0. [Case study](https://www.anandms.com/work/stock-trader-recommendations)
- **[Outpost](https://github.com/anandms101/AIwithoutBorders).** Offline clinical triage on a single Dell GB10, which a teammate and I built for a Dell and NVIDIA hackathon. The only thing that leaves the machine is a 124-byte summary a person has approved.
- **[CodeCollab](https://github.com/anandms101/dev-finder-2.0).** Rooms for pair programming that I built on my own, with video through Stream. Next.js, NextAuth and PostgreSQL.
- **[SceneSnap](https://github.com/anandms101/SceneSnap).** An offline-first iOS app for recreating movie scenes. We built it with SwiftUI and Firebase on a team of three.
